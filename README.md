# რეზიდენტურის ტესტები

შინაგანი მედიცინის რეზიდენტურის საგამოცდო ტესტები (შედგენილი ს. ტატიშვილის მიერ, 3521 კითხვა).
მობილურზე მორგებული სტატიკური ვებ-აპი: კითხვა პასუხებით, ტესტი, ჯგუფები, ჩანაწერები, შეცდომების სია, სტატისტიკა, ფილტრი წლისა და თემის მიხედვით, ქართული და ინგლისური ინტერფეისი.

Static, dependency-free web app. Progress (answers, notes, groups, test history) is kept in the browser (`localStorage`). Works offline after the first load and can be added to the phone's home screen. The AI tutor exists only in the claude.ai version of this page; this build hides it.

## Files

| File | Purpose |
|---|---|
| `index.html` | the whole app, generated by `build.py` (do not edit by hand) |
| `build.py` | wraps the page source into a standalone document and turns the AI features off |
| `bank.json` | the question bank: `n` number, `q` text, `opts` options, `ans` index of the correct option, `t` topic, `y` year (0 = none), `k` kind, `p` question pattern |
| `manifest.json`, `sw.js`, `icon.svg`, `icon-*.png` | installable app and offline cache |

## Run locally

Any static server works. For example:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Opening `index.html` directly from the file system does not work, because the app loads `bank.json` with `fetch`.

## Update the app

1. Rebuild: `python3 build.py <path to the page source>`.
2. Raise `CACHE` in `sw.js` (for example `rt-v2` to `rt-v3`), otherwise phones that installed the app keep the old version.
3. Commit and push to `main`. GitHub Pages redeploys within a minute.

## Host on GitHub Pages

Settings, Pages, Source: Deploy from a branch, branch `main`, folder `/ (root)`. The site is served at `https://<user>.github.io/<repo>/`.

## Updating the question bank

`bank.json` was generated from the original Excel file. Each entry needs exactly one correct option; the index in `ans` is zero-based and matches the order in `opts`.
